# Fonts

Latin-subset WOFF2 files, served from the app's own origin. All three are
licensed under the SIL Open Font License 1.1.

- Atkinson Hyperlegible (Braille Institute): all reading and interface text
- Atkinson Hyperlegible Mono (Braille Institute): small labels
- IM Fell English (Igino Marini): the wordmark and card names
